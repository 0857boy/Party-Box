目前簡單 60 組、普通 368 組、困難 57 組。每個分類都有三種難度。
設定的難度是**精確篩選**，不是選困難時混入所有簡單題；預設「全部難度」適合連續玩。

- 簡單：熟悉，差異相對明顯，例如貓／狗、前任／現任。
- 普通：有共同情境與可描述差異，例如雞排／鹽酥雞、鍋貼／水餃。
- 困難：外觀、用途或互動高度相近，但有可描述的差異，例如海豹／海獅、按讚／收藏。
- 淘汰：合作社／福利社、老師／補習班老師、仙人掌／多肉植物、好人卡／朋友卡等同義或包含關係過強的配對。

難度是編輯判斷，不是冷門度排名，也未宣稱經過玩家實測。實際聚會回饋可以調整分級或退回 draft。
暗戀／單戀的兩種特徵可以同時成立，不因「很像」就列為困難題。
影片創作者也可能直播，因此採「預錄影片／即時直播」對比內容形式，而非硬分互相重疊的身分。

## 結構與編輯規則

入口為 `src/games/undercover/data/words.ts`，十四個分類檔位於 `data/pairs/`。
`definePairs.ts` 讀取逐行的六個欄位：

```text
food-01|N|雞排|鹽酥雞|夜市油炸雞肉；可撒胡椒粉|雞排通常是一大片；鹽酥雞通常切成小塊
```

欄位依序為固定 ID、E/N/H 難度、兩個詞、共同特徵、可描述差異；「；」拆成備註陣列。
這是壓縮的編輯格式，不是隨機組合詞彙。輸出的 WordPair 有 tags、sharedTraits、differences、difficulty、status。
reviewed 只表示已完成本次編輯查核，不表示教育部審核遊戲，也不表示真人實測過。

修正錯字或移分類保留 ID；換成不同配對用新 ID，舊 ID 不再重用。
使用短詞與情境名稱，避免完整句子。最多七字（含 YouBike 等名稱）；多數中文詞更短。
不要以「有差異」取代具體差異，也不要為了製造數量，把同義詞或同一概念的母子類別配在一起。
一個詞可以用於不同配對，只禁止完全相同、反向相同或正規化後相同的**詞組**。

共同特徵／差異只是維護資料，**不會顯示在設定預覽、秘密抽詞或遊玩畫面**，session 也不保存這些提示。
這是完全離線的靜態 PWA，不存在保密後台：有開發者工具的人仍可閱讀客戶端題庫。不能把「不顯示」誤稱為伺服器層保密。

## 可靠來源與範圍

不是下載字典後按字面相似度自動配詞，也沒有複製整段釋義。
大多數情境由 Party Box 自行編輯；字典用於核對詞目或有疑慮的語意，官方生活資料提供候選與背景。

  新 `data/source-checks.json` 留下原始行號與 SHA-256 `5bab99dac44ad7a6ccdcf481e770e8aca05ede7445c4cc25b8199e0e5df64cf2`。
  這是字面詞目核對，**不是 177 組配對通過語意驗證，也不是全部 485 組都查過字典**。
  它從既有 charades 已核對快照抽出同詞目，單元測試確認來源版本、行號與題庫詞目仍對得上。
- [教育部「福利社」](https://dict.revised.moe.edu.tw/dictView.jsp?ID=38412&la=0&powerMode=0)：確認機構內消費設施語意，用於福利社／便利商店。
- [教育部「波羅蜜」](https://dict.concised.moe.edu.tw/dictView.jsp?ID=114&la=0&powerMode=0)：修正水果名為台灣辭典寫法。
- [教育部「麻糬」](https://dict.revised.moe.edu.tw/dictView.jsp?ID=26803&la=0&powerMode=0)：確認糯米製品語意；不用麻糬／大福的包含型配對。
- [教育部「暗戀」](https://dict.revised.moe.edu.tw/dictView.jsp?ID=148123&la=0&powerMode=0)及[「單戀」](https://dict.revised.moe.edu.tw/dictView.jsp?ID=43745&la=0&powerMode=0)：兩者可重疊，淘汰此組。
- [交通部觀光署小吃飲品](https://www.taiwan.net.tw/m1.aspx?sno=0000072)：夜市小吃候選，雞排／鹽酥雞等背景，不是全庫品質認證。
- [海巡署生物多樣性與保育研討會資料](https://www.cga.gov.tw/GipOpen/wSite/public/Attachment/f1518078642762.pdf)：核對海豹／海獅外耳差異。

逐項查核連結與範圍也在 `data/references.ts`。不要把自編分類、差異或難度標成教育部內容。
教育部原始[公眾授權說明](../public/licenses/moe-concised-public-license.pdf)保留並提供於完整規則；原始來源檔案與核對工具沿用[比手畫腳來源流程](charades-deck.md)。
目前沒有 GBIF 大量匯入或任何不存在的外部人工審核紀錄。

## 抽題、防重複與本機儲存

1. 按主題和精確難度取 reviewed 詞組。
2. 先排除所有曾用 pair ID，再優先挑兩個詞都沒用過的配對。
3. 沒有完全新詞配對時，允許個別詞再次出現，但仍不重複詞組。
4. 這個篩選池的詞組全部用完，回傳 null，停止抽題並提示換設定或重洗。
5. 重洗要明確確認，只移除目前主題／難度篩選出的歷史，其他題庫歷史保留。
6. 平民／臥底詞每局隨機對調，白板仍沒有詞。

`party-box:undercover:draw-history` version 1 只存 `usedPairIds`，從目前題庫反推已用詞。
歷史跨分類與難度共用、重新整理仍存在，不保存哪位玩家拿到哪個詞、陣營、當局結果或推理備註。
本局身份仍只留在記憶體；秘密畫面重新整理會回設定。
棄局也算抽過，以防不斷重抽相同詞。清除網站資料會一併清除歷史。
若瀏覽器拒絕 Local storage，當前頁面仍以記憶體防重複，重新整理後無法保留。
靜態題庫與 ID 可被開發者工具讀取，不承諾防止技術性作弊。

## 驗證

```bash
npm run check:undercover
npm run test
npm run build
npx playwright test tests/e2e/undercover-vocabulary.spec.ts tests/e2e/minimal-setup.spec.ts --project=mobile
```

品質驗證在建置前自動執行：ID／反向詞組重複、NFKC／大小寫／空白、非法分類、詞長、缺少共同點／差異、draft 混入、已淘汰配對回歸及非動物混入動物區。
這些檢查不能自動判斷任意新詞組是不是同義詞或好不好玩；新增時仍需編輯檢查並用玩家回饋校準。
邏輯測試另覆蓋新詞優先、只重複詞但不重複詞組、抽完回傳 null、隨機換方向、損毀資料復原與舊設定相容。
瀏覽器測試覆蓋所有主題／難度、跨主題與重新整理防重複、明確重洗、隱私畫面不渲染備註、離線啟動、實際完整對局及重玩。
